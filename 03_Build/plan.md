## 0. How to read this plan

- **Module = Course Map module** (10 modules + Midterm + Final). The `units.md` "Unit" numbers differ in order; the source-mapping is given per module so the builder reads the right `units.md` entry.
- **Callout codes** used in the weekly tables: **H** = history-of-science callout · **C** = contemporary-research callout · **AI** = AI-literacy callout · **WI** = web-interactive element. "(—)" means none planned for that lesson; not every lesson carries every callout (CLAUDE.md: "where appropriate," not box-checking).
- **OpenStax source** is the internal adaptation source for the builder only. Per the hard rules, OpenStax is **never named on student-facing pages** (single course-level disclosure handles attribution).
- Every normal week (all except 15 & 36) delivers the full CLAUDE.md package: **4 readings + 4 lessons + 4 paired assignments + 1 reading quiz + 2 VR activities**, plus the module CER (assigned module start, due module end) and the quarterly VR project (assigned quarter start, due quarter end).
