Lesson focus: A cell built to fire an all-or-none signal
📋 ASSIGNMENT OVERVIEW
This assignment has three short parts: match each neuron part to its function, explain how the sodium–potassium pump sets the resting potential, and put the action-potential steps in order. It should take about 15–20 minutes.
🎯 FOCUS QUESTION
How does a single cell stay charged and ready, then fire a message down its length in an instant?

2
Part B — The resting potential (3 pts). In one or two sentences, explain how the sodium–potassium pump keeps the inside of a resting neuron negative. Include the ratio (how many Na⁺ out for how many K⁺ in) and name the process it is an example of from Module 3.
3
Part C — Order the action potential (3 pts). Number these events 1–3 in order: Repolarization (K⁺ out) · A stimulus crosses threshold · Depolarization (Na⁺ in). Then write one sentence explaining what "all-or-none" means.
✅ SUCCESS CRITERIA
☐
Part A: dendrites → A, axon → B, myelin → C, axon terminals → D.
☐
Part B: the pump uses ATP to move 3 Na⁺ out for every 2 K⁺ in, pushing out more positive charge than it brings in, so the inside stays negative. It is an example of active transport (Module 3).
☐
Part C order: 1. A stimulus crosses threshold, 2. Depolarization (Na⁺ in), 3. Repolarization (K⁺ out). "All-or-none" = the neuron either fires a full-strength signal or none at all; a stronger stimulus makes it fire more often, not bigger.
