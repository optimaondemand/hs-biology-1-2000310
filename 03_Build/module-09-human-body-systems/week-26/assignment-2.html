Before you begin: finish Reading 26.02 and work through Lesson 26.02, including the four parts of a negative feedback loop, the temperature and blood-glucose examples, and the difference between negative and positive feedback.
Lesson focus: The body governs itself by opposing change
📋 ASSIGNMENT OVERVIEW
This assignment has three short parts: match each part of a feedback loop to its job, answer one true/false about what “steady” means, and explain in a sentence or two why sweating on a hot day is negative feedback. It should take about 15–20 minutes.
🎯 FOCUS QUESTION
How does the body hold a value steady against a changing world?
📝 STUDENT DIRECTIONS
1
Part A — Match the loop part to its job (5 pts, 1 each). Match each part of a feedback loop to what it does, using the list below.
Part of the loop Its job (write the letter)
Stimulus 
Receptor 
Control center 
Effector 
Response (in negative feedback) 
A. The change that starts the loop (e.g., temperature rises)  ·  B. The sensor that detects the change  ·  C. Compares the reading to the set point and decides (usually the brain)  ·  D. The muscle or gland that carries out the action  ·  E. Opposes the change, returning the body toward the set point
2
Part B — True or false (2 pts). Write True or False and correct it in a few words if false: “Homeostasis means the body keeps a value perfectly, unchangingly constant.”
3
Part C — Explain the loop (3 pts). In one or two sentences, explain why sweating on a hot day is an example of negative feedback. (Hint: what does the response do to the temperature change?)
✅ SUCCESS CRITERIA
☐
Part A: stimulus → A, receptor → B, control center → C, effector → D, response → E.
☐
Part B: False — values drift up and down; homeostasis means the body keeps correcting them back toward a set point, not holding them perfectly constant.
☐
Part C explains that sweating cools the body, which opposes the temperature rise and returns it toward the set point — the defining feature of negative feedback.
