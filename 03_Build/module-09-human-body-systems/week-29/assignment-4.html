Lesson focus: Continuing the species, and the body as one integrated whole
📋 ASSIGNMENT OVERVIEW
This assignment has three short parts: fill in the reproduction-and-meiosis links, answer one true/false about hormonal control, and trace one substance across several body systems to show the body works as one whole. It should take about 15–20 minutes.
🎯 FOCUS QUESTION
How does the reproductive system carry life to the next generation — and how do all the body's systems add up to one living whole?
📝 STUDENT DIRECTIONS
1
Part A — Fill in the blanks (4 pts, 1 each). Complete each sentence with the correct term.
(i) Sperm and eggs are produced by the cell division called ____________.
(ii) Because each gamete carries ____________ (how much?) of the chromosome set, fertilization restores the full number.
(iii) The union of a sperm and an egg is called ____________.
(iv) The reproductive system is switched on and coordinated by hormones from the ____________ system.
2
Part B — True or false (2 pts). Write True or False and correct it in a few words if false: “Gametes are made by mitosis, so each carries a full set of chromosomes.”
3
Part C — Trace a molecule (4 pts). In two or three sentences, trace one substance (oxygen or glucose) across at least three body systems, naming each system and what it does, to show the body works as one integrated whole.
✅ SUCCESS CRITERIA
☐
Part A: (i) meiosis; (ii) half the chromosome set; (iii) fertilization; (iv) endocrine system.
☐
Part B: False — gametes are made by meiosis, so each carries half a chromosome set (the full set is restored at fertilization).
☐
Part C names at least three systems correctly (e.g., oxygen: respiratory takes it in → circulatory carries it → cellular respiration in the mitochondria uses it; or glucose: digestive absorbs → circulatory distributes → endocrine keeps it steady).
