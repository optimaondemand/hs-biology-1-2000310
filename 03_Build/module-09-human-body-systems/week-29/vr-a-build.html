Week 29 · VR-A (Build / Model)
Model a Vaccine Triggering B/T-Cell Memory
Solo VR activity · ~30 minutes · 10 pts (completion)
🔬 WHAT YOU’RE DOING
You will build a giant, walk-through timeline of a vaccine response and assemble it in order: an antigen is introduced → the matching B/T lymphocyte is selected → clonal expansion multiplies it → antibodies and memory cells form → on re-exposure, a faster, stronger second response. Then you will record a short walkthrough narrating each stage. Building the sequence as a space you can step through makes the abstract idea of immune memory concrete — you can literally walk from the first exposure to the fast second response. This is Lessons 29.02 and 29.03, built in space.
🔧 WHAT YOU’LL NEED
A VR headset (recommended) or the ENGAGE desktop app · your completed Readings 29.02–29.03 and Lessons 29.02–29.03 · your scientific notebook.
📍 HOW TO JOIN
Device: VR headset or desktop · Session type: temporary
Session ID: posted by your teacher at the top of this Canvas assignment
Location: Immunity Lab / Lymph Node Interior (Optima VR library)
On arrival: go to the empty five-step sequence frame marked by the Whiteboard IFX. A sticky note there gives your first instruction — begin by introducing the antigen.
📝 WHAT TO DO, IN ORDER
1
Introduce the antigen. Place the antigen object (the harmless piece the vaccine presents) in the first frame and label it: a vaccine shows this antigen safely — no live, replicating pathogen.
2
Select the matching lymphocyte. From a rack of different B and T cells, pick the one whose receptor matches the antigen and move it into the second frame. Label it: clonal selection — only the matching lymphocyte is chosen.
3
Clonal expansion. Duplicate that lymphocyte into a cluster of identical copies in the third frame. Label it: the selected cell multiplies into an army of clones (this is why the first response takes days).
4
Antibodies and memory cells form. In the fourth frame, show B cells releasing antibodies AND set aside long-lived memory B and T cells. Label it: immunity is stored in the memory cells — not in antibodies that last forever.
5
Re-exposure, then record. In the fifth frame, bring the real pathogen back and show the memory cells launching a faster, stronger response. Then start a spatial recording and, in about 60–90 seconds, walk the five frames in order, naming each stage. End by pointing to the memory cells as the reason the second response is so fast.
📤 WHAT TO SUBMIT
Upload your spatial recording to this Canvas assignment. If you can’t record, submit one full snapshot of your labeled five-step sequence (all frames visible) plus typed labels naming each stage in order, and a sentence saying why the memory cells make the second response faster.
⏱️ TIME · ABOUT 30 MINUTES IN-HEADSET
Facilitator note: Students externalize the vaccine-memory sequence by building it stage by stage. Two common errors to watch for and correct: saying antibodies are what "remember" the enemy (the lasting memory is in memory B and T cells; antibodies fade), and skipping clonal selection (only the ONE matching lymphocyte is chosen and multiplied). A strong submission shows all five frames in correct order with accurate labels, memory cells clearly set aside in stage 4, and a walkthrough that correctly credits the memory cells for the fast second response.
✅ SUCCESS CRITERIA (COMPLETION)
☐
All five stages are built and labeled in correct order (antigen → matching lymphocyte selected → clonal expansion → antibodies + memory cells → faster second response).
☐
Memory B and T cells are clearly shown and identified as what stores immunity; only the matching lymphocyte is selected and multiplied.
☐
A spatial recording (or full snapshot + typed labels) is submitted, naming each stage and explaining why the second response is faster.
