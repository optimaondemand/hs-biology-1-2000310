Innate Immunity
Reading 29.01 and Lesson 29.01
Before you begin: finish Reading 29.01 and work through Lesson 29.01, including the first line (barriers) and second line (inflammation, fever, phagocytes, NK cells, complement), and the three words that define innate immunity.
Lesson focus: Defenses you are born with — fast, general, no memory
📋 ASSIGNMENT OVERVIEW
This assignment has three short parts: sort innate defenders into first or second line, answer one true/false about how the innate system responds, and explain in a sentence or two why innate immunity is called fast, general, and memoryless. It should take about 15–20 minutes.
🎯 FOCUS QUESTION
How does the body defend itself against invaders before it has ever met them — and what does “innate” really mean?
📝 STUDENT DIRECTIONS
1
Part A — First line or second line? (5 pts, 1 each). For each defender, write “First line” (a barrier that keeps invaders out) or “Second line” (the inner response after a barrier is breached).

2
Part B — True or false (2 pts). Write True or False and correct it in a few words if false: “The innate immune system remembers each microbe it has fought and responds faster the next time.”
3
Part C — In your own words (3 pts). In one or two sentences, explain why innate immunity is described as fast, general, and memoryless, using one example.
✅ SUCCESS CRITERIA
☐
Part A: skin → First line; phagocytes → Second line; stomach acid → First line; inflammation and fever → Second line; mucus and cilia → First line.
☐
Part B: False — the innate system does NOT remember; it responds the same way every time. Memory belongs to the adaptive system (memory B and T cells).
☐
Part C names all three traits: fast (acts in minutes/hours), general (treats most invaders alike), no memory (same response every time), with a correct example (e.g., a phagocyte eats any microbe without identifying it).
