Lesson · Recombinant DNA and Gel Electrophoresis
📖 TODAY'S FOCUS
If the genetic code is universal, can a human gene be read by a bacterium?
Yes — and that single fact built biotechnology. Today you will learn the four moves that define genetic engineering: cut DNA with restriction enzymes, combine it using sticky ends, paste it with DNA ligase into a plasmid, and sort the pieces with gel electrophoresis — which separates DNA by size.

✂️ PART 1 · CUT, COMBINE, PASTE

Four tools, one recombinant molecule

Restriction enzymes are molecular scissors: each recognizes one specific short DNA sequence and cuts there (EcoRI cuts at GAATTC), often leaving single-stranded sticky ends. Because any two DNA pieces cut with the same enzyme have complementary overhangs, they pair up by the base-pairing rule from Week 11. A plasmid — a small circular piece of bacterial DNA — is cut with the same enzyme to serve as a vector (a carrier). When a gene’s sticky ends pair into the cut plasmid, DNA ligase seals the backbone, producing recombinant DNA: one molecule carrying DNA from two sources. Slipped into bacteria (transformation), the recombinant plasmid is read and its protein made.

Sort the tools to make the sequence stick.

🧪 PART 2 · SORTING DNA BY SIZE

Gel electrophoresis

To see the fragments you have cut, you load them into wells in a slab of gel and switch on an electric current. DNA’s backbone is negatively charged, so every fragment is pulled toward the positive electrode. The gel is a dense mesh: smaller fragments slip through and travel farther; larger fragments are held back, near the wells. Say the key idea carefully, because it is easy to flip: gel electrophoresis separates DNA by size, not by charge (all fragments share the same negative charge), and the smaller fragments are the ones that travel farther.

Negative DNA → toward the + electrode · sorted by SIZE
Small fragments travel farther from the wells; large fragments stay close to the wells.

🔗 PART 3 · WHY IT ALL WORKS

Step back and notice the deep reason recombinant DNA is possible at all: the genetic code is universal (Week 12). The same A–T, G–C pairing and the same code that turns a gene into a protein operate in a bacterium exactly as in a human. That is why a human gene, pasted into a bacterial plasmid, can be faithfully read and built. The shared code that you will later see as evidence for common ancestry (Module 6) is the same shared code that lets engineers move a gene between kingdoms of life and have it still work.
