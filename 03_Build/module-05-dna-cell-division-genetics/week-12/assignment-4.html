🎯 FOCUS QUESTION
How does a single changed base in one gene reach all the way out to bend a red blood cell into a sickle?
📝 STUDENT DIRECTIONS
1
Part A — Fill in the trace (6 pts, 2 each). Complete the three blanks in the trace table below for the beta-globin mutation in sickle-cell disease.
Link Your answer
The mRNA codon changes from GAG to ___ (i) 
So the amino acid changes from glutamic acid to ___ (ii) 
This kind of substitution (codes a different amino acid) is called a ___ mutation (iii) 
2
Part B — Shape to phenotype (4 pts). In two to three sentences, explain how this single amino-acid swap leads to a sickle-shaped red blood cell. Use the idea that a protein’s function depends on its folded shape.
✅ SUCCESS CRITERIA
☐
Part A is correct: (i) GUG, (ii) valine, (iii) missense.
☐
Part B explains that the swap (hydrophilic Glu → hydrophobic Val) makes hemoglobin clump when oxygen is low, distorting the cell into a sickle — shape changes, so function changes.
