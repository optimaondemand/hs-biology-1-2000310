📖 WHAT THIS BUILDS ON
Reading the Code
Reading 12.02 and Lesson 12.02
Before you begin: finish Reading 12.02 and work through Lesson 12.02, including codons, the start codon AUG, stop codons, and where translation happens. You will need a codon chart (use the vetted tool linked in the lesson, posted by your teacher).
Lesson focus: the ribosome reads mRNA in three-letter codons; translation happens at the ribosome in the cytoplasm
📋 ASSIGNMENT OVERVIEW
Three short parts: read codons off an mRNA strand, identify the start and stop signals, and answer the transcription-vs-translation location question. The whole assignment should take about 15–20 minutes.
🎯 FOCUS QUESTION
How does the ribosome know where to start reading, where to stop, and which amino acid each codon calls for?
📝 STUDENT DIRECTIONS
1
Part A — Break it into codons (3 pts). Take this mRNA strand and divide it into codons (groups of three), then circle the start codon and the stop codon.
mRNA strand:
A U G   C A C   G U G   U A A
2
Part B — Translate it (4 pts). Using a codon chart, list the amino acids coded between the start and the stop codon, in order. (You should get three amino acids before reading stops.)
3
Part C — Where does it happen? (3 pts). In one or two sentences, state where transcription happens and where translation happens, and name the molecule that travels between the two.
✅ SUCCESS CRITERIA
☐
Part A correctly groups AUG·CAC·GUG·UAA and marks AUG as start, UAA as stop.
☐
Part B lists the amino acids for AUG, CAC, GUG in order (methionine, histidine, valine), stopping at UAA.
☐
Part C says transcription is in the nucleus, translation is at the ribosome in the cytoplasm, and mRNA travels between them.
