Reading 12.02
Reading the Code
Anchor Reading · Translation, Codons, and the Genetic Code
📖 WHAT YOU ARE READING TODAY
The message has been copied and has left the nucleus. Now it must be read. This is the anchor reading for Lesson 12.02. By the end you should be able to explain translation — how a ribosome reads messenger RNA in three-letter codons and builds a chain of amino acids — identify the start and stop signals, and explain why the genetic code being nearly the same in every living thing is one of biology’s great clues.

Three letters at a time

An mRNA strand is a string of just four letters — A, U, G, C — yet it must spell out instructions for building proteins from twenty different amino acids. How? The cell reads the message three letters at a time. Each three-letter unit is a codon, and each codon specifies one amino acid (or a start/stop signal). With four letters in groups of three, there are 64 possible codons — more than enough to cover all twenty amino acids, with some redundancy to spare.

So a sequence like AUG-GCU-AAA is read codon by codon, each one calling for a specific amino acid, in order. The order of codons in the mRNA sets the order of amino acids in the protein — and, as you will see this week, that order is everything.

Translation at the ribosome

Translation is the building of a protein from the mRNA message, and it happens at the ribosome — a machine of rRNA and proteins found in the cytoplasm (floating free or studding the rough ER). The ribosome clamps onto the mRNA and moves along it one codon at a time.

For each codon, a matching transfer RNA (tRNA) arrives. Each tRNA carries a specific amino acid at one end and, at the other, a three-letter anticodon that base-pairs with the mRNA codon. When the anticodon matches the codon, the ribosome adds that tRNA’s amino acid to the growing chain. The ribosome shifts to the next codon, the next tRNA arrives, and the chain lengthens — amino acid by amino acid — until a stop signal is reached.

A common mix-up to avoid: transcription and translation do not happen in the same place. Transcription is in the nucleus; translation is at the ribosome in the cytoplasm. The mRNA is the courier that travels between the two.

Where to start and where to stop

A message is useless if you don’t know where it begins. Reading always starts at a start codon, AUG, which also codes for the amino acid methionine. From there the ribosome reads forward in steady three-letter steps, setting the reading frame — the way the letters are grouped into codons.

Reading ends at one of three stop codons — UAA, UAG, or UGA. These code for no amino acid; they are punctuation that tells the ribosome the protein is finished. The finished amino-acid chain then folds into its working three-dimensional shape — the link back to Module 2, where you learned that a protein’s job depends on its precise folded form.

One code for (almost) all of life

Here is one of the most striking facts in all of biology: the genetic code is essentially universal. AUG means “start” in a bacterium, an oak tree, a jellyfish, and you. GUG codes for the same amino acid in nearly every organism on Earth. The dictionary that turns codons into amino acids is shared across life with only tiny exceptions.

Why does that matter? It is powerful evidence that all living things share a common ancestor — a single ancient origin from which the code was inherited (a thread we pick up in Module 6 on evolution). And it has a practical payoff you will meet in two weeks: because the code is universal, a human gene placed inside a bacterium is read and built correctly by the bacterium’s own ribosomes. That shared dictionary is the very reason biotechnology can make bacteria produce human insulin.

💪 WHY THIS MATTERS

You can now follow a message from start codon to stop, codon by codon, into a finished protein. That makes you ready for the most important question of the week: what happens when the original instructions contain a mistake? A single wrong letter changes a codon, and a changed codon can change an amino acid — and a changed amino acid can change a life. That is exactly where the next two lessons go.
