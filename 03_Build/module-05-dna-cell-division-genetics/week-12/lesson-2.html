📝 PART 1 · THREE LETTERS AT A TIME

Codons and the ribosome

The ribosome reads mRNA three letters at a time. Each three-letter unit is a codon, and each codon names one amino acid (or a start/stop signal). For each codon, a matching tRNA arrives carrying its amino acid; the tRNA’s three-letter anticodon base-pairs with the codon, and the amino acid is added to the chain. Reading begins at the start codon AUG and ends at a stop codon (UAA, UAG, or UGA), which codes for no amino acid — it is punctuation.

Where does this happen? Translation occurs at the ribosome in the cytoplasm — not in the nucleus. Transcription (nucleus) and translation (cytoplasm) happen in two different places, with the mRNA as the courier between them. This is a favorite trap question, so lock it in.

🔍 PART 2 · TRY THE CODON CHART YOURSELF

Biologists use a codon chart — the dictionary that turns each three-letter mRNA codon into its amino acid. With it you can translate any mRNA sequence by hand: find the codon, read off the amino acid, move to the next codon.

🌍 PART 3 · ONE CODE FOR ALL OF LIFE

Why universality is a clue — and a tool

The genetic code is essentially universal: AUG means “start” and GUG codes for the same amino acid in a bacterium, an oak, and you. Two big consequences. First, it is powerful evidence of a shared common ancestor — a thread you pick up in Module 6. Second, it has a practical payoff coming in Week 14: because the code is universal, a human gene placed inside a bacterium is read correctly by the bacterium’s ribosomes. That shared dictionary is exactly why biotechnology can make bacteria produce human insulin.
